# Data-Analytics-Portfolio
A collection of real-world Data Analytics projects demonstrating data cleaning, Excel dashboards, KPI reporting, data visualisation and actionable business insights.
## Australia Logistics Dashboard

An interactive Excel dashboard exploring shipment volumes, delivery performance, customer ratings and revenue across Australian regions and couriers.

- **KPIs:** Total shipments, on-time delivery rate, average delivery days, average customer rating and total revenue.
- **Filters:** Destination region and shipping mode.
- **Tools:** Excel, PivotTables, PivotCharts, slicers and GETPIVOTDATA.

[Download the Excel workbook](Australia_Logistics_Delivery.xlsx)

Open the downloaded workbook in desktop Excel to use the interactive slicers.
